# Stays API v11 overview

#### The Travelport+ Hotel v11 APIs are a robust, flexible set of RESTful JSON endpoints that empower developers to build seamless, beautiful hotel booking experiences with global reach and real-time data.

Built for developers, our APIs are designed to integrate easily into your applications, enabling you to build rich, responsive hotel booking interfaces tailored to your users.

#### Guides

Overviews and best practices for searching, booking, and managing hotel reservations.
For business and technical users seeking to understand capabilities and workflows.

Start with the [TripServices Stays APIs Guide](/docs/stays/guides/stays-general-guide)

#### Stays API reference

Intended for developer-level technical audiences. Each reference describes a single API, including method, endpoint/s, object-level details including supported formats and values, and example requests and responses.

Check out the [Stays API reference](/apis/stays)
